# colbert_golden fixtures — provenance

Both files were generated by the encoder-feasibility prototype's Python
reference script (the reference Python ColBERT implementation's exact,
index-free `rerank`, CPU; see `docs/adr/0002-pure-jvm-colbert-signal.md`),
running the `answerdotai/answerai-colbert-small-v1` checkpoint — the SAME
checkpoint the JVM encoder loads.

- `token_ids.json` — Python `QueryTokenizer`/`DocTokenizer` golden output:
  exact `input_ids` + `attention_mask` for 3 queries (MASK-padded to
  `query_maxlen` 32, attention 0 on MASK padding) and 3 documents (no padding).
- `python_scores.json` — reference exact-rerank scores + rankings for the
  3 queries x 6 documents corpus (`rank` here is the reference's 0-indexed
  rank). The version field inside the JSON records the exact reference
  package pin the scores were captured with.

The prototype independently verified them: JVM-vs-Python rankings identical,
max |score delta| 0.00001, and a hand re-derivation of MaxSim from dumped
embeddings reproduced the scores to machine precision. The prototype harness
itself was throwaway; these fixtures and this note are the durable artifact.

Tests read these from the test classpath (`resources/colbert_golden/...`),
never from `development/`.
