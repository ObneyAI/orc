## Three narrow limits

- Boolean `:abstain false` fails public build-time membership validation even though false is offered. Valid false decisions without that option still succeed. Use described enum clarify/defer for an explicit abstention route; preserve this engine repair obligation.
- Conversational answers and Noul supply no Choice confidence. A floor abstains on absent confidence, not on a derived probability-certainty measure. Choice uses declared reporting resolution, so rounded ties may be valid routing evidence. The stricter unique-maximum score-only judge policy is separate.
- Native decision completions preserve the provider-resolved model, but ordinary conversational leaf completion events currently retain the configured/requested node model instead. Capture actual prediction/HTTP response model separately and keep both fields labeled. Do not call the event field an exact resolved identity for ordinary generation.

Shared budget admission prevents further registered model calls across delegated descendants. The cancellation lifecycle still has a reproduced trace/publication defect: an active child can be cancelled without its canonical trace, and interrupting its worker can strand root cancellation after durable append but before live delivery. Read [tool proof limits](../../orc-tools/references/current-proofs-and-limits.md) before claiming prompt family cancellation or complete family monitoring. Native Score and multilabel policy remain custom integrations; judge scheduling fixes are separate work.

## Decision stage and live eligibility

A fresh parallel consumer's native eligibility gate selected clarify before invoking tools for a replenishment request, producing an honest failure with no domain effect. The same unchanged tree completed when its runtime request explicitly described reading stock/price, computing the observed shortfall and keeping the task read-only. These are separate observed outcomes, not a calibration dataset or proof of the model's internal reason.

Describe the gate's stage precisely: whether a task is supported by the offered capabilities is different from whether sufficient observations have already been gathered. A gate before retrieval should evaluate whether the planned reads can answer the task; a post-retrieval check should evaluate the actual evidence. Exercise representative selected/defer paths through the real provider instead of treating a forced fixture answer as semantic proof. Keep an honest defer outcome; do not retry an unchanged decision until a desired choice appears.
