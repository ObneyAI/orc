The current full consumer tool suite has **15 tests / 80 assertions, zero failures, one error**. Its earlier 15 / 84 green result predates strict family trace readiness and is not the current acceptance result. **15 obligations, 15 covered, 14 satisfied, 1 unmet.**

Two remaining lifecycle gaps were exposed:

1. A cancelled active child has durable cancellation facts but no canonical trace. Trace assembly subscribes to normal tree completion, not cancellation. Raw events are evidence, not a satisfied trace-publication obligation.
2. Child cancellation interrupts the same leaf worker while it dispatches root cancellation. The root cancellation can already be committed in SQLite when the interrupted caller fails before event publication/result delivery. The root caller then waits until timeout or is labeled wedged rather than receiving prompt budget cancellation.

The bounded public reproducer has **one test / seven assertions, four passes and three failures**. Keep it failing for a separate engine repair. Do not relax readiness, count timeout/wedged failure as prompt cancellation, or fabricate normal completion facts for cancelled work. Verify every started terminal family execution's trace and original identity, cancellation return/delivery, exactly one terminal fact and no late effects. Reliable durable terminal reconstruction must include cancellation when opportunistic notification was lost.

Nominal recursion and parallel work still succeeded. This defect does not mean budget admission fails or tools are generally broken. Execution leases protect recovery ownership but do not themselves supply coherent family cancellation publication or durable judge jobs.

## Versioned workspace evidence and diagnostic access

A later controlled consumer exercised actual root/delegate/code tool callers, concrete described contracts, scoped Grain projections, complete-read edit authority, whole-batch stale refusal, a one-shot independently announced feature, exact protected acceptance receipts and currentness invalidation. These native mechanics do not establish fresh-author transfer or all-model semantic quality.

When a diagnostic is previewed, an artifact path alone does not make the omitted evidence available to the agent. Provide complete evidence within admitted context or a described receipt-scoped retrieval capability with exact stream identity, raw-byte hash, decoding and progressing continuation offsets. Keep original bytes and historical receipt/revision identity; retrieving a log does not make an old acceptance current or grant source-edit authority. A final later chunk need not mean one chunk contained the entire stream. Index historical receipts rather than repeatedly embedding full code/log bodies; retain the responsibility's relevant original artifacts separately.

Artifact capture must not bypass tool-process cleanup. One actual confined-worker fault probe reproduced a save error leaving its timed-out child alive; independent cleanup in a nested finally killed/joined the child while preserving the capture failure. The native root proof then closed all actual Futures/bodies/processes before its store/cache. This supports those bounded mechanisms, not arbitrary-code security or filesystem crash-atomic effects. No per-model parser or semantic repair helper was added.
