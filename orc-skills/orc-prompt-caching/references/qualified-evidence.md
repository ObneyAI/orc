## Gateway debug boundary

Six streaming debug samples (Haiku, GLM, Qwen pairs) were HTTP 200 with genuine terminal usage and strict-valid reassembled content. Gateway-reported upstream bodies showed only the later variable text changing; static instruction, schema and earlier text were unchanged. Haiku/Qwen retained the marker; GLM dropped it. No message flattening was shown. Qwen therefore did NOT fail because the visible gateway lost its marker. GLM's marker removal is an observed disconnect, but implicit caching and unseen routing/provider internals prevent a complete causal attribution.

Raw SSE/debug echoes remain restricted private artifacts. Reassembled content is labelled a protocol-level concatenation, never replacement raw bytes. These samples do not establish blocking gateway equivalence, native packet capture, role-cache behavior for all models or a universal parser fix.
